Setup Firebase

Masukkan konfigurasi Firebase kamu supaya data tersimpan di cloud dan bisa diakses dari HP & laptop.

1

Buka Firebase Console

Pergi ke console.firebase.google.com → Buat project baru → Beri nama "budget-huda"

2

Tambah Web App

Klik ikon web </> → Register app → Copy konfigurasi yang muncul

3

Aktifkan Firestore

Di sidebar kiri → Build → Firestore Database → Create database → pilih Start in test mode

4

Paste konfigurasi di bawah ini

Menempel sekaligus menghindari salah ketik dan autofill yang mengembalikan nilai lama.

Semua field wajib diisi!

💾 Backup & Restore Data

    
Simpan atau pulihkan seluruh data keuanganmu


    

      
⬇️ Export Backup

      
Download semua data (semua tahun & bulan) sebagai 1 file JSON. Simpan file ini di tempat aman sebagai cadangan.

      
    


    

      
⬆️ Restore dari Backup

      
Pulihkan data dari file backup. ⚠️ Ini akan menambahkan data dari file ke akun yang sedang login (tidak menghapus data yang sudah ada).
